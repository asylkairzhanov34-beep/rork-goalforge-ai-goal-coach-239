# Добавить нативный таймер в Dynamic Island и на экран блокировки

## Features
- [x] Показывать основной Focus/Pomodoro таймер в Dynamic Island сразу после старта сессии.
- [x] Показывать тот же таймер на экране блокировки и в центре уведомлений.
- [x] Отображать точное оставшееся время секунда в секунду.
- [x] Показывать аккуратный прогресс-бар, чтобы было видно, сколько сессии уже прошло.
- [x] Автоматически скрывать таймер после завершения или остановки сессии.
- [x] Сохранять корректное отображение времени, если пользователь свернул приложение.

## Design
- [x] Сделать максимально нативный iOS-стиль, как у аккуратных системных Live Activities.
- [x] Использовать чистую темную подложку, светлый текст и мягкие акценты без перегруза.
- [x] В компактном виде оставить только самое важное: иконку и оставшееся время.
- [x] В расширенном виде показать название Focus-сессии, точный таймер и тонкий прогресс-бар.
- [x] На экране блокировки сделать спокойный, премиальный вид без лишних кнопок.

## Pages / Screens
- [x] Экран таймера: при запуске Focus-сессии автоматически включает отображение в Dynamic Island.
- [x] Dynamic Island: показывает живой обратный отсчет для текущей Focus-сессии.
- [x] Экран блокировки: показывает расширенный вид таймера с прогрессом.
- [x] Центр уведомлений: сохраняет видимый таймер, пока сессия активна.

## Behavior
- [x] Работать только для основного Focus/Pomodoro таймера.
- [x] Не добавлять быстрые действия внутри Dynamic Island.
- [x] Поддерживать одинаковое время в приложении, Dynamic Island и системном отображении.
- [x] Завершать отображение сразу после окончания таймера, чтобы не оставалось устаревшего статуса.
