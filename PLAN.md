# Исправить отображение таймера вне приложения на iPhone

## Features
- [x] Таймер показывается в Dynamic Island, на экране блокировки и в шторке уведомлений.
- [x] Во внешнем отображении есть кнопки паузы, продолжения и остановки таймера.
- [x] Состояние таймера синхронизируется вне приложения без рассинхрона.
- [x] При сворачивании и повторном открытии приложение сохраняет правильное время и статус таймера.
- [x] Улучшена стабильность запуска внешнего таймера, чтобы он не пропадал сразу после старта.
- [x] При завершении основной focus-сессии звук окончания проигрывается 3 раза и сопровождается лёгкой вибрацией.

## Design
- [x] Компактный вид в Dynamic Island с заметной иконкой и оставшимся временем.
- [x] Расширенный вид с более крупным таймером и понятным статусом: идет или пауза.
- [x] Экран блокировки и шторка уведомлений показывают крупное время и заметные элементы управления.
- [x] Внешний вид сохранён в стиле приложения: темный фон, яркий акцент и чистая иерархия текста.

## Pages / Screens
- [x] Экран таймера: запуск, пауза и остановка правильно передаются во внешнее отображение.
- [x] Dynamic Island показывает активный таймер и быстрое состояние с первого взгляда.
- [x] Экран блокировки отображает живой таймер во время активной сессии.
- [x] Шторка уведомлений показывает рабочие кнопки паузы, продолжения и остановки без необходимости заходить в приложение.
